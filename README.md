## מה חדש בגרסה 10.9
- **פלייליסטים בעיצוב חדש**: חלון עם כל השירים לפי הסדר — בוחרים בדיוק מה להוריד, רואים מה המגן חוסם ומה כבר הורדת, ושומרים בתיקייה בשם הפלייליסט, ממוספר לפי הסדר
- **הורדת פלייליסטים אמינה יותר**: גם פלייליסטים של YouTube Music ואלבומים, וכל שיר נבדק בנפרד במגן
- **פלייליסטים ברשת של נטפרי**: התוכנה עוברת על השירים אחד-אחד ומציגה רק את מה שנטפרי מאשר
- **מאיץ הורדות חדש ומובנה** — מוריד בכמה חיבורים במקביל, בלי להתקין שום תוסף
- **חיתוך שקט בתחילת השיר** — מסירים את הקטע הריק שלפני שהשיר מתחיל
- **מאות ערוצים חדשים בחיפוש הסגור**, כולל ערוצי הדף היומי
- **כשנטפרי או רימון חוסמים סרטון** — הודעה ברורה "ההגנה של נטפרי חסמה את הסרטון", וכפתור להעתקת הקישור לבקשת אישור (בלי להוריד את רמת ההגנה)
- הודעה ברורה כשהאנטי-וירוס במחשב חוסם קובץ שירד, או עוצר את קובץ העדכון
- **פתיחת החלון**: תוקנה התקלה "לא הייתה אפשרות ליצור את ספריית הנתונים" — החלון נפתח תמיד
- **לחיצה כפולה על הקיצור** כשהתוכנה כבר פתוחה — מקפיצה את החלון הקיים
- **עובד טוב יותר ברשת של נטפרי** — תעודות האבטחה של נטפרי מובנות בתוכנה ובמתקין
- **חלון "אודות" חדש** (תפריט תחזוקה): התקנון, רישיונות רכיבי הקוד הפתוח ודרך ליצור קשר
- **כפתור "העתק" בבדיקת מערכת** — נוח לשלוח כשמבקשים עזרה
- שמירה בטוחה של ההגדרות, ההיסטוריה והתור, גם בסגירה פתאומית

## מה חדש בגרסה 10.8
- **"עיון"** (בחירת תיקיית הורדה) ו**"נגן"** עובדים גם במחשבים נעולים/מסוננים — הן פועלות ישירות דרך Windows ולא דרך תוכניות עזר שעלולות להיחסם
- **"עדכן כלים מהאתר הרשמי"**: מיד מוצג בסרגל מה קורה, ובסוף תמיד מופיעה תוצאה ברורה
- כל כשל בשלושת הכפתורים מוצג עכשיו בעברית עם הסבר, במקום "לא קורה כלום"

## מה חדש בגרסה 10.7
- עדכון מתוך התוכנה עובד גם בנטפרי

## מה חדש בגרסה 10.6
- **עדכון מתוך התוכנה תוקן**: התוכנה בודקת גרסה חדשה בכל פתיחה (ולא פעם בשבוע), ו"עדכן עכשיו" מוריד קובץ קטן, מחליף את התוכנה ופותח אותה מחדש — בלי שאלות
- כפתור "הורד ידנית" בפס העדכון, למקרה שההורדה נכשלת

## איך מפרסמים גרסה חדשה (למפתח)
1. Releases ← Draft a new release ← תג `v<גרסה>` (למשל `v10.9`)
2. גוררים את `morid_update_<גרסה>.exe` ואת `morid_setup_<גרסה>.exe` (החבילה המלאה) — בשמות האלה בדיוק, באנגלית
3. Publish release — התוכנות מגרסה 10.6 ומעלה מוצאות את הגרסה לבד
4. בשביל גרסאות 10.5 ומטה ונטפרי: עותק של קובץ העדכון בשם `morid_update_<גרסה>_web.exe` בשורש המאגר, ועדכון `version.json`
